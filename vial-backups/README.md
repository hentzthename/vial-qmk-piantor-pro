# Vial keymap backups

Piantor Pro Vial/VIA keymap snapshots exported with `vitaly save`.
Back up here before any keymap change so edits have git history:

```
vitaly save ~/source/vial-qmk-piantor-pro/vial-backups/piantor-pro.vil
```

Restore with `vitaly load <file>`. See `~/.claude/CLAUDE.md` for the full
agent workflow.
